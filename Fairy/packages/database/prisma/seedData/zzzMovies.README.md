# zzzMovies — 绝区零 Random Play 影像店影片数据

`zzzMovies.ts` 收录了《绝区零》中 **Random Play 影像店（录像店）** 的全部 39 部录像带/影片节目，
字段与 `prisma/seed.ts` 中 `seedMovies` 完全同构，可直接替换或合并进 seed 脚本。

**2026-10-11 已导入**：`seed.ts` 影片循环为 `for (const movie of [...seedMovies, ...zzzMovies])`（按 `title` upsert，幂等），
跑 `pnpm --filter=@fairy/database db:seed` 即导入/刷新。绝区零片单与 `seedMovies` 现实片单**同库共存**——前者带封面，
后者留作无封面 CSS 占位的对照。导入后 dev 库 47 部影片（39 绝区零 + 8 原有），真机 39 张封面全部渲染、0 破图。

## 数据来源

- 页面：绝区零 BWIKI（观测枢）**录像带** <https://wiki.biligame.com/zzz/录像带>
- 抓取日期：2026-10-10（页面由旅行者酒馆攻略组维护，CC BY-NC-SA 4.0）
- 游戏内获取途径（店铺升级 / 街道支线 / 光映广场小卡格车）见下方参考表，不属于 `Movie` schema 字段，仅作留存。

## 字段口径

| 字段                   | 来源                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `title`                | 游戏内原名                                                                                                                              |
| `genres` 首个标签      | 游戏内「类型」（纪实/怀旧/冒险/幻想/喜剧/动作/惊悚/悬疑/访谈/都市/时尚/灾难/悲剧/亲情/广告/爱情）                                       |
| `description`          | 游戏内简介（已修正原页面明显错别字：「攻击者」→「攻击着」、「阻击手」→「狙击手」、「市区归宿」→「失去归宿」等）                         |
| `director`             | **虚构占位**。游戏未公布导演/制作方，填入了自拟的新艾利都片方名（如「以太映画」「邦布工坊」）                                           |
| `year`                 | **虚构占位**。游戏未公布上映年份，按影片内容所处的旧文明/近代/当期排了 2252–2287 的演示年份                                             |
| `quote`                | 由简介改写的宣传语，非游戏内原文                                                                                                        |
| `moods` / `scenes`     | 按简介基调人工归类，取值限于 schema 枚举：moods ∈ 治愈/热血/悬疑/致郁/轻松/浪漫；scenes ∈ 雨天/失眠夜/周末午后/独自在家/约会夜/通勤路上 |
| `stock` / `totalStock` | 演示库存，按游戏内等级（3级片库存更少）分配                                                                                             |
| `coverUrl`             | 指向同目录 `covers/` 下的本地海报图（见下节）                                                                                           |

## 导入方式

方式一：直接替换 seed。把 `zzzMovies` 引入 `prisma/seed.ts` 并替换 `seedMovies`（upsert 逻辑不变）：

```ts
import { zzzMovies } from "./seedData/zzzMovies";
const seedMovies = zzzMovies;
```

方式二：临时导入脚本（不动 seed.ts），`tsx` 跑一遍 upsert 即可，字段同上。

注意：seed 脚本在 `NODE_ENV=production` 下会拒绝执行；且 upsert 以 `title` 为唯一键，
重复导入只会更新库存等字段，不会产生重复影片。

## 封面素材

海报图的**唯一存放位置是 `apps/web/public/covers/`**（39 个 PNG，182 × 292 px，约 4.6 MB），与 `zzzMovies.ts` 中 `coverUrl` 一一对应（`/covers/<影片名>.png`，文件名即游戏内片名）。

- 来源：与影片数据相同，取自 BWIKI「录像带」页海报列（patchwiki.biligame.com），CC BY-NC-SA 4.0
- 规格：PNG，182 × 292 px，共 39 个文件约 4.6 MB
- `zzzMovies.ts` 中 `coverUrl` 存 `/covers/<影片名>.png`（前导斜杠形态，SPA 任意路由下可解析），seed 导入后库中即该值
- **数据库只存这个路径字符串，不存图片字节**：`Movie.coverUrl` 是 `String?` 列，`seed.ts` 从不读取任何图片文件。图片由 web 的静态托管（dev 为 Vite `public/`，生产为 nginx）按该路径下发，因此删改本目录以外的任何副本都不影响 seed 与封面渲染

**2026-10-10 已落地静态托管**（需求 [2026-10-10-movie-cover-display.md](../../../../docs/requirements/2026-10-10-movie-cover-display.md)，影片库 `MovieCard` 封面展示）：39 个 PNG 已复制到 `apps/web/public/covers/`，`zzzMovies.ts` 的 `coverUrl` 已由相对路径 `covers/...` 改为 `/covers/...`，`<img src>` 直接用，无需再改数据。

**2026-10-20 已清理本目录下的重复副本**：`seedData/covers/` 曾是海报的初始位置，静态托管落地后成为零引用的 4.6 MB 冗余（全仓无任何代码引用，`seed.ts` 不读图片文件），已删除。实测验证：移走该目录后 `db:seed` 照常导入 47 部影片、39 条 `coverUrl` 不变，封面经 web 仍返回 HTTP 200 且 PNG 有效。

若后续版本新增录像带，以 BWIKI 页面为准补充：海报图**只放入 `apps/web/public/covers/` 一处**，`zzzMovies.ts` 的 `coverUrl` 直接写 `/covers/<影片名>.png`，并同步更新本表。
